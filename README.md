# Calculator App

A simple Java Calculator application created to demonstrate a Maven-based CI/CD pipeline using Jenkins and SonarQube.

## Technologies Used

- Java 17
- Maven
- JUnit 5
- Jenkins
- SonarQube
- GitHub
